# ゆるガイドのデザインの決まりごと

日本語の文字組み・コントラスト・ボタンの大きさ・動きなどの一般的な決まりは、全体用の `ja-typography` スキルを先に読む。このファイルには、このサイトで決めた値と、このサイトだけの決まりを書く（ぶつかったら、こちらを優先）。

デザインの元は Figma Make の書き出し `D:\WebPages\figma-design`（`src/index.css` と `src/App.tsx`）。数字や形はまずそこを見て、なければこのファイルの決まりに従う。勝手に新しい見た目を発明しない。

## 1. 色と線と影
- 色は `css/base.css` の `:root` の変数だけを使う。
  - 地と線：`--paper`（地）、`--white`（カード・箱）、`--ink`（線・文字・暗い地）
  - アクセント：`--coral` / `--blue` / `--yellow` / `--green`
  - 決勝までの道：Top（上位）は赤 `--top`、Bot（下位）は青 `--bot`
  - ダークモードあり（`css/dark.css`。`<html data-theme="dark">` のときだけ効く）。ページの地を夜の深緑 `--night` にして、カード・ナビ・窓などの紙の部品はライトの色のまま浮かせる。地の上にじかに書いた文字と線だけクリームに入れかえ、ずらし影は `--night-shadow`（クリームのうすい影）。新しい部品を足したら、ダークでも見て直す。
  - 左下の切りかえボタンは仮（ユーザーが確認用に使っている）。サイトができたら外す。
- 線は `--ink` で太め：カードは 3px、小さい部品は 2px。
- 角の丸みは角ごとに少しずつ変えて手描きっぽくする（例 `25px 19px 29px 18px`）。4つの角が同じ丸みにはしない。
- 影はぼかさず、ずらしたベタの影にする（`3px 3px 0 var(--ink)`。深緑の地の上では `rgba(246,240,228,.24)`、窓ではコーラル）。ぼかした影やグラデーションは使わない。
- 傾けるのは ±0.25°〜2° まで。並ぶものは交互に向きを変える。スマホでは傾けない（読みやすさ優先）。
- 押したときは影がへこむ（ずれを小さくして translate する）。マウスをのせたときは少し浮くか、少し回る。

## 2. 書体
- 見出し・数字の大きい飾り：`--f-head`（Yusei Magic、weight 400 のみ。太字にしない）
- 本文・ボタン・ラベル：`--f-body`（M PLUS Rounded 1c。使える太さは 500 / 700 / 800）
- スコア・点数などの数字：`--f-num`（Chakra Petch）
- 字間の広い英字ラベル（APEX LEGENDS GLOBAL SERIES など）は、新しくは増やさない（ユーザーが保留中）。

## 3. このサイトで決めた文字組みの値（一般的な決まりは ja-typography）
- Yusei Magic の大きい見出しは `letter-spacing:-.04em〜-.06em`。Yusei Magic は文字のまわりの余白が広いので、-.06em でも文字はくっつかない（ブラウザで確認済み）。
- Chakra Petch の数字は、漢字の下にそろえるため `position:relative;top:.045em` 下げる（測って決めた値。「1試合目」の数字）。
- 決勝の帯の「11/2」「8:00」は、Yusei Magic の数字が細くて読みにくいので、本文の書体（M PLUS Rounded 1c）の 800・1.05 倍にした。「(月)」は 0.6 倍、「〜」は 0.7 倍。
- スライドのタイトル：「決勝」1 倍＋「スタート」0.92 倍、「1」1.4 倍＋「試合目」0.92 倍。見えない文字で下のラインを固定している。
- 縦書きの英字ラベル（MAP GUIDE など）は、カードを傾けているのでずれて見えるが、カードの向きに合っているのでそのままでいい（ユーザー確認済み）。

## 4. このサイトの文字の大きさの下限（PC。ja-typography の目安より、ユーザーの指摘で少し大きめ）
- 本文・説明：15px 以上（カードの中の説明は 13px 以上）
- 補足（「20チーム・マッチポイント制」など）：14px 以上
- 英字の小ラベル：13px 以上。11px 以下は「読みにくい」と言われた
- 見出しの下の説明文：16px 以上
- スマホは、PC より 1〜2px 小さくしてもいい。ただし 11px を下回らない。

## 5. ボタンと押せる場所
- 押せる場所は 44×44px 以上（スマホでは特に）。小さい見た目のボタンでも、押せる範囲は広げる（帯や行全体を押せるようにする）。
- 帯や見出しが開け閉めのボタンなら、帯のどこを押しても反応させる（矢印や＋の丸だけにしない）。
- 大事な行動（観戦しにいく・再生など）は大きく、アイコン＋文字にする。文字だけの小さいボタンにしない。
- 押したら出るもの（選ぶリンクなど）は、押したボタンのそばに出す。画面の真ん中の窓より近い方がいい。外を押す・Esc で閉じる。
- 窓は `<dialog>` の `showModal()` で開いて、後ろのページはスクロールさせない（`:root:has(... :modal){overflow:hidden}`）。

### このサイトの読みやすさ・さわりやすさ（一般的な決まりは ja-typography の 7・8 章）
- キーボードで選んだときの枠は、ふだんはコーラル。コーラルの地の上（01 のカード `#win` の中）では深緑。
- `--coral` は文字に使うと薄すぎる。白い地にコーラルの字・コーラルの地に白い字は `--coral-ink` を使う。
- 動きの曲線は `var(--ease-out)` を使う。スライド（動画）の中の動きは「中身」なので、この決まりの外。
- 動きを減らす設定の人への対応は、`css/base.css` の最後にまとめてある。

## 6. 配置
- 余白は 8 の倍数を基本にする（8 / 12 / 16 / 24 / 32 / 48）。カードの中の余白は PC 24〜34px、スマホ 17〜22px。
- PC のナビは、上の真ん中に浮かぶクリーム色のバー（参考：https://games.parco.jp/page/constance/）。スマホは右上の四角いボタンと、左のふちがヨレた紙のパネル。
- セクションの境目は、まっすぐな線よりギザギザや波線にする。

## 7. 作業の進め方
- ファイルの分け方：共通は `css/base.css`・`js/site.js`、セクションは `css/<id>.css`・`js/<id>.js`。セクションのセレクタは全部 `#<id>` から始める。
- ユーザーは自分でも CSS を直す。ファイルが変わっていたら、それを今の状態として受け取る。
- 文言（コピー）はユーザーが決める。仮の文言には「仮」とコメントを書いておく。
- 調整パネル：URL に `?tune` を付けると `js/dev-tune.js` が出る。ユーザーがここでいじった差分（コピーしたもの、またはブラウザの `localStorage` の `dev-tune` / `window.devTune.css`）を受け取ったら、そのまま貼らずに直す。
  - `/* 移動: … */`（translate）は仮の値なので、margin や配置の指定に直す。
  - 「画面の幅 ○px で調整」は、その幅の `@media` に入れる（PC の幅なら、ふだんの指定に）。
  - `/* メモ: … */` はユーザーからの要望として読む。

## 8. これまでの指摘（同じことを言わせない）
- PC で小さくて読めなかった文字：「APEX LEGENDS GLOBAL SERIES」、見出しの下の説明文、「20チーム・マッチポイント制」 → 4章の下限を守る
- 「観戦しにいく」が小さすぎた → 大きいテレビのアイコン（中に LIVE）にして、押すとまわりに3つのリンクが出る形にした
- タイトルの「決勝」が大きすぎ、「スタート」が小さすぎた → 1倍と 0.92 倍で落ち着いた
- 数字が漢字より浮いて見えた → 3章のとおり下げてそろえる
- 50pt の棒の頭とタイトルが重なった → 重なりは測って、ずらす量（px）を報告する
- 手作り感は「全部同じ角丸・グラデーション・ぼかした影」をやめることで出る
