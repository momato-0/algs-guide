# ALGS はじめて観戦ガイド

ALGS をはじめて観る人のための、ファンが作った非公式ガイド。GitHub Pages で公開する。

## フォルダ構成

- `index.html` … ページ本体。セクションは `<section class="sec" id="…">` で並べる
- `css/base.css` … サイト共通（色の設定、文字、目次、ヒーロー、フッター、開け閉めの三角ボタン `.fold`）
- `css/<セクションID>.css` … セクションごとの見た目。セレクタは全部 `#<セクションID>` から始める
- `js/<セクションID>.js` … セクションごとの動き。ID は `<セクションID>-` で始める
- `img/` … 画像
